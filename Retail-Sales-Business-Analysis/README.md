# Retail Sales & Business Performance Analysis
**Status: Starter — analysis and dashboard pending.**

Analyze retail transactions for revenue trends, product performance, regional sales, and customer purchasing patterns.

**Planned stack:** Python (pandas, NumPy), SQL, Excel, Power BI.

## Workflow
1. Select a public retail dataset and document its source/license in `data/README.md`.
2. Add the dataset to `data/` (the folder is git-ignored for CSVs).
3. Run `python src/clean_data.py` after adapting column-specific cleaning rules.
4. Complete EDA in `notebooks/`.
5. Adapt `sql/retail_analysis.sql` to the dataset schema.
6. Build the Power BI dashboard and document verified findings.

This is a starter scaffold, not a completed analysis. Add only verified results to this README.
